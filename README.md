# 세이프빌드 (SafeBuild)

건설 현장의 안전을 한 걸음 더 든든하게 준비한다는 뜻을 담은 세이프빌드(SafeBuild)입니다. 공종과 하도급 계약금액을 입력해 산안비 예시 시뮬레이션을 확인하고, 공종별 초기 위험요인 목록을 매핑하는 브라우저 시제품입니다.

## 실행

Node.js 18 이상에서 프로젝트 폴더로 이동해 아래 명령을 실행한 뒤 `http://127.0.0.1:4173`을 여세요. 별도 패키지 설치는 필요하지 않습니다. 서버는 이 컴퓨터에서만 접속할 수 있도록 로컬 주소에 바인딩됩니다. 저장한 프로젝트는 현재 브라우저의 로컬 저장소에만 보관됩니다.

```powershell
node server.js
```

계산 로직의 단위 테스트는 아래 명령으로 실행합니다.

```powershell
npm test
```

## 중요: 시뮬레이션 데이터

화면의 기본 대상액 비중(65%)과 예시 요율(3.11%)은 동작 확인용 값이며, 현행 법정 요율을 뜻하지 않습니다. 실제 계상액은 적용 대상 공사 분류, 대상액 산정 등 계약금액만으로 알 수 없는 조건에 따라 달라집니다. 따라서 결과를 법정 계상액, 청구액 또는 정산액으로 사용하면 안 됩니다.

위험요인과 대책도 공종별 초기 예시이며 고용노동부·안전보건공단의 공식 데이터 인용이나 특정 현장에 대한 위험성평가가 아닙니다. 실제 서비스에 적용하기 전에는 현행 고시와 공식 위험성평가 자료를 확인·검토하고, 출처·시행일·버전을 관리하는 검증된 데이터로 교체해야 합니다.
